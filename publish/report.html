Reproduce
Download and keep the complete report directory, including every copied raw bundle and report-builder receipt. Restore the exact adapter builds at their locked paths on a compatible host, then run the commands below from the report directory. Each attached pass runs separately and sequentially. The exact recorded runner is used from the current executable or its sealed tool archive; unavailable or changed tools fail preflight without starting measurements. Default verification only reads files and uses the current analysis/renderer.
For an older report, --recorded-builder explicitly executes its archived builder to retain the original analysis/renderer. Use this only for reports you trust to execute: checksums prove consistency, not publisher trust. The archive stays non-executable; a temporary hash-checked copy runs on its recorded OS/architecture. Reports created before builder archival require separately recovering their original builder. Reproduction is not a claim of identical performance or official publication.
